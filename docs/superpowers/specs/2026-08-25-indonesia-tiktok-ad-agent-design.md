# 印尼 TikTok 家清产品广告自动化剪辑 Agent 设计规格

**文档状态：** 已通过设计审核，待实施
**版本：** 1.1
**日期：** 2026-08-25

## 1. 项目目标

为不熟悉 AI 的内部运营人员提供一个浏览器操作界面。运营人员提交产品资料、产品图片和可选视频素材后，系统自动完成素材检查、广告策划、分镜、AI 补镜头、剪辑渲染和审核流转，输出一条可下载、可人工复核的印度尼西亚 TikTok 竖屏产品广告初版。

MVP 聚焦单任务生产：一次提交一款产品，生成一条可审核广告。首个样板品类为厨房清洁剂。后续再扩展批量生产、剪映执行、发布和数据反馈。

## 2. 设计原则

1. 创意表达优先。产品事实、包装、Logo、颜色、容量和合规要求作为不可突破的硬边界，而不是削弱创意的默认理由。
2. 业务规则负责识别和拦截，AI 负责分析、解释、生成建议与候选内容。
3. 产品三视图、分镜、AI 视频和最终成片都保留人工确认节点。
4. 系统内部以 `edit_plan.v1` 为剪辑事实来源，不绑定剪映、Remotion 或单一 Agent 框架。
5. 已完成的镜头和任务状态持久化，失败后只重做失败部分。
6. 对运营人员隐藏模型参数和底层工具，只呈现业务语言和明确操作。

## 3. MVP 范围

### 3.1 包含

- 公司授权邮箱和密码登录，不提供公开注册。
- 跨设备访问、任务恢复和云端状态保存。
- 视频素材、产品图片、混合素材三种输入模式。
- “完整广告创作”和“只剪现有素材”两种任务目标。
- 产品资料、宣传边界和证明材料录入。
- 产品图片分析、候选三视图和九宫格广告分镜生成。
- 素材技术预检、内容分析、合规提示和片段评分。
- 印尼语广告脚本、字幕文本和可替换配音任务。
- Seedance 2.5 缺失镜头生成适配层。
- FFmpeg 基础合成与 Remotion 视觉包装。
- 镜头级预览、重试、降级、版本和费用记录。
- 内容审核与最终批准记录。
- TikTok 9:16 成片下载。

### 3.2 不包含

- 自动发布 TikTok 和广告投放。
- 批量商品和批量账号生产。
- 完整团队权限系统或公开注册。
- Cloudflare Linux 容器直接运行剪映桌面端。
- 无人工确认的全自动产品宣称或最终发布。
- 以 AI 推测图替代真实包装资料。

## 4. 用户与默认输出

主要用户为公司内部运营人员。MVP 可由同一人完成内容审核与最终批准，但系统分别记录两个动作，为后续职责分离预留接口。

默认输出参数：

- 平台：TikTok
- 市场：印度尼西亚
- 画幅：9:16
- 语言：印尼语字幕和印尼语配音
- 时长：根据有效卖点与镜头表达需要决定，不设置固定秒数
- 目标：产品主体明显、核心卖点清楚、包装信息一致、可直接进入人工复核

## 5. 输入与事实边界

### 5.1 两种任务目标

1. **完整广告创作：** Agent 可以在用户授权范围内完成脚本、三视图、九宫格分镜、缺失镜头生成、字幕、配音和剪辑包装。
2. **只剪现有素材：** 仅处理用户提供的素材包，不生成三视图、分镜图、AI 视频、新卖点或额外广告文案。用户勾选允许执行的剪裁、排序、拼接、字幕、配音、贴纸、转场和音乐操作，系统不得超出勾选范围。

“只剪现有素材”仍执行文件技术预检和必要的内容识别，以保证素材可用和正确切点，但不把分析扩展成内容生成。其流程为：

`上传素材包与剪辑要求 -> 技术预检 -> 形成剪辑任务单 -> 自动剪辑 -> 人工审核`

### 5.2 三种输入模式

1. **视频素材模式：** 上传本地实拍视频和产品锚点图。
2. **产品图片模式：** 上传产品图片，由系统规划并生成广告镜头。
3. **混合模式：** 实拍视频和产品图片共同输入，由 AI 补充缺失镜头。该模式是默认推荐路径。

视频素材不再是必填项。视频或产品图片至少提供一种；只上传视频时，仍应补充一张清晰产品锚点图，否则进入“需要补资料”。

### 5.3 必填业务资料

- 产品名称、品类、目标人群和使用场景
- 可验证的产品事实和核心卖点
- 已批准宣传表述
- 禁用表述和已知合规限制
- 清晰产品主体图或可识别产品的视频素材
- 使用方法和期望行动号召

检测报告、认证、活动价格凭证、品牌规范和参考广告为可选资料。涉及杀菌率、无毒、安全、认证等高风险宣称时，对应证明材料转为必填；缺少依据时系统不得写入脚本。

## 6. 产品参考图与 AI 生成规则

原始产品图始终是产品事实基准。系统可根据单张产品图生成候选三视图，未经人工确认不得进入正式分镜或视频生成。

AI 来源提示不嵌入图片、不添加水印，也不成为导出素材的一部分。来源、参考原图和待确认状态仅作为第三步“确认方案”中的界面元数据及后台溯源记录。用户确认后的导出图片保持干净，但系统内部仍保留来源记录。

产品参考包包括：

- 用户上传的原始产品图和真实多角度图
- 产品透明底图
- Logo、包装文字、容量和关键标签局部图
- 包装颜色、形状、材质和尺寸说明
- 经人工确认的候选三视图
- 标记为 AI 预览的场景图和九宫格分镜

推荐顺序为：

`原始产品资料检查 -> 候选三视图 -> 人工确认 -> 广告脚本 -> 九宫格分镜 -> 人工确认 -> 逐镜头视频生成`

上传产品主视图后，用户可明确选择“生成三视图”“生成九宫格分镜”或“两者都生成”。选择发生在资料提交阶段，结果统一在第三步“确认方案”中展示和确认。

只有一张正面图时，系统优先生成广告分镜，不把推测的产品背面当作真实信息。

## 7. Agent 判断链

1. **技术预检：** 检查格式、时长、分辨率、方向、音轨、损坏文件和重复素材。
2. **内容分析：** 抽取代表帧并转写音频，识别产品露出、使用动作、问题、效果和包装信息。
3. **合规与来源初审：** 对照批准卖点、禁用词、证明材料和素材来源；不确定项进入人工确认。
4. **片段评分：** 按相关性、清晰度、稳定性、产品可见度、动作完整度、重复度和一致性排序。
5. **脚本与分镜：** 按“问题、产品、演示、效果、行动号召”组织内容，再匹配实拍或生成镜头。
6. **缺口判断：** 列出缺少镜头、生成理由、预估成本和产品一致性风险。
7. **人工确认：** 对候选三视图、九宫格分镜和 Seedance 生成任务分别确认。
8. **计划输出：** 生成 `edit_plan.v1` 并交给渲染适配器。

## 8. `edit_plan.v1` 剪辑协议

`edit_plan.v1` 是系统内部统一任务单，至少包含：

- 任务、产品、市场、平台和版本标识
- 输出尺寸、帧率、时长和语言
- 镜头顺序、素材来源、入点、出点和轨道
- 每个镜头的用途、产品露出要求和一致性检查项
- 印尼语字幕、配音文件、时间码和音量
- 卖点卡片、Logo、贴纸、转场和品牌样式
- Seedance 生成来源、提示约束、用户确认记录和成本
- 合规提示、证明资料引用和人工审核状态
- 渲染结果、错误、重试次数和版本关系

协议必须可校验、可版本化。渲染器只执行允许字段，不能执行 Agent 生成的任意命令或任意文件路径。

## 9. 执行组件职责

- **Codex Agent：** 主控编排、素材分析、脚本与分镜规划、缺口判断、工具调用和结果解释。通过适配层允许后续替换为其他 Agent 框架。
- **FFmpeg：** 裁剪、拼接、音轨处理、基础字幕和稳定编码，也是 Remotion 或剪映不可用时的基础输出路径。
- **Remotion：** 动态字幕、贴纸、卖点卡片、品牌动画和更丰富的可编程视觉包装。
- **Seedance 2.5：** 按已确认分镜逐镜头生成缺失画面。默认用于场景、氛围和过渡；包含产品的镜头进入实验路径并加强审核。
- **配音适配器：** 接入公司现有配音软件；供应商未确定前保持可替换接口。
- **剪映适配器：** 后续导出剪映草稿 ZIP，或在专用 Windows/Mac 执行机上通过自动化操作剪映。剪映失败不阻断云端基础成片。

AI 生成场景与真实产品信息冲突时，优先使用“AI 场景背景 + 真实产品图 + Remotion 动画与文字”的降级组合。

## 10. 云端架构

### 10.1 推荐结构

- Cloudflare 托管浏览器前端、登录入口、API、任务编排和访问控制。
- 持久数据库保存用户、任务、状态、审核、版本和费用信息。
- R2 或等价对象存储保存源素材、中间产物和最终视频。
- 任务队列拆分分析、图片生成、视频生成和渲染步骤。
- Cloudflare Container 作为 Remotion/FFmpeg 渲染候选执行环境。
- 外部模型和配音服务通过后端适配器调用，密钥只保存在服务端环境变量或密钥系统中。

### 10.2 已知边界

- 域名只提供访问地址，不提供计算和存储。
- 使用 Cloudflare 托管时，MVP 不必先购买阿里云 ECS；阿里云购买的域名可以解析到 Cloudflare。
- Cloudflare Containers 不是免费渲染资源，需要付费计划，并且必须使用真实素材验证 Remotion、FFmpeg、字体、浏览器依赖、临时磁盘和任务时长。
- 临时磁盘不能作为长期存储，源文件和输出必须写回对象存储。
- Cloudflare Linux Container 不能运行剪映桌面端。

如果容器实测不能稳定完成目标渲染，应保持前端与任务层不变，仅把渲染适配器迁移到独立云服务器或专用执行机。

## 11. 任务状态与恢复

主状态为：

`草稿 -> 已上传 -> 分析中 -> 需要补资料/等待生成确认 -> 可渲染 -> 渲染中 -> 待内容审核 -> 待最终批准 -> 已批准`

异常状态为“失败可重试”或“已取消”。每一步保存输入版本、输出位置、执行次数和错误类别。页面关闭、网络中断或换电脑不终止云端任务。相同步骤使用幂等标识，避免重复点击产生重复扣费或重复任务。

## 12. 重试、降级与费用控制

- 正式生成前先提供低成本分镜或预览。
- 默认每个镜头最多自动尝试两次，仍不合格则暂停并说明原因。
- 产品主体或包装不一致时停止盲目重试，降级为真实产品图后期合成。
- 成功镜头单独保存，失败后只重做指定镜头。
- 生成前显示预计镜头数、预计尝试次数和预估费用。
- 每个任务设置费用上限，超过上限必须人工确认。
- 所有面向公司运营人员展示的预估费用、任务费用和月度费用统一以人民币计费。
- 用户重复提交、回退或刷新页面不能导致重复计费。
- 每次生成保留版本、模型、输入摘要、费用、审核人和选择结果，不覆盖旧版本。

## 13. 浏览器界面

1. **任务列表：** 显示产品、市场、创建人、状态、费用和更新时间，可恢复未完成任务。
2. **新建广告：** 先选择“完整广告创作”或“只剪现有素材”，再选择输入模式并提交对应资料；完整创作默认印度尼西亚 TikTok。
3. **AI 方案确认：** 查看素材质量、风险、脚本、镜头顺序、三视图、九宫格分镜和待生成镜头，并逐项确认。AI 来源以图片外部的界面标签显示，不写入图片。
4. **视频审核台：** 播放成片，按时间查看字幕、配音、卖点和风险；批准、退回或重做单个镜头。
5. **成品与版本：** 下载成片，查看历史版本、费用和审核记录；后续增加剪映草稿与发布入口。

界面使用业务语言，不展示 FFmpeg、Remotion、提示词或底层模型参数。典型按钮为“分析资料”“确认分镜”“生成初版”“重做这个镜头”“批准下载”。

任务列表中的产品头像统一从用户上传的产品主图自动截取；没有可用主图时才显示通用占位图，不使用产品名称首字母代替产品图。

审核顺序为：

`AI 初版 -> 运营内容审核 -> 合规/负责人最终确认 -> 批准下载`

## 14. 安全与合规

- 仅公司授权邮箱可创建账号或登录，不提供公共注册。
- 密码使用不可逆哈希保存，登录会话采用安全 Cookie 和过期机制。
- 上传、查看、下载和审核动作按公司身份记录审计日志。
- 上传类型、大小、文件名和媒体内容进行服务端校验，存储使用不可预测对象键和限时访问地址。
- API Key 只在后端使用，不写入前端、代码仓库、文档、日志或示例环境文件。
- 产品宣称的最终批准责任属于人工；系统必须展示风险和依据缺口。
- 素材和生成结果设置保留期限，删除策略在部署前由公司确认。

## 15. MVP 验收标准

使用同一款印尼市场厨房清洁剂，分别完成“仅产品图片”“产品图片 + 实拍视频”和“只剪现有素材”三条任务。验收要求：

- 授权用户可以跨设备登录并恢复任务。
- 三种输入模式可用，缺少必要事实时能阻止继续。
- 单张产品图可以生成候选三视图和九宫格分镜，并保留人工确认。
- 可以生成完整印尼语脚本、字幕和配音任务。
- Seedance 缺镜头任务经人工确认后执行，只重试失败镜头。
- 成片为 9:16，产品包装、颜色、Logo、容量和卖点清晰。
- 未提供依据的功效、认证、成分和夸大宣传不会进入已批准成片。
- 字幕、配音和画面基本同步。
- 页面关闭或换电脑后云端任务继续，失败时提供可理解的原因和处理动作。
- 版本、费用和审核记录可查看，成品可下载。
- 剪映不可用时，FFmpeg 与 Remotion 路径仍能生成可审核初版。
- “只剪现有素材”任务不生成三视图、九宫格、AI 视频、新卖点或额外广告文案，只执行用户勾选的剪辑操作。

## 16. 实施前待验证项

以下事项不阻止设计定稿，但必须在实施计划或技术验证阶段明确：

- 公司现有配音软件的名称、API、授权方式和商用边界
- Seedance 2.5 实际可用接口、输入约束、价格、并发和内容政策
- Cloudflare Container 的具体账户配额与真实素材渲染表现
- 目标字体、音乐、贴纸和模板的印尼市场商用授权
- TikTok 印度尼西亚市场的最新广告政策和家清品类禁限用表述
- 公司授权邮箱名单维护方式、素材保留期限和最终审核负责人

## 18. 界面迭代记录

**迭代目的：** 根据首次可操作原型反馈，补齐纯剪辑任务边界、产品参考图生成入口、人民币费用和产品主图头像。

**设计依据：** 保留已验证的运营工作台、任务表格、四步流程和审核台结构，按照 Kang Frontend Standard 进行局部增强，不在需求仍变化时重做整套视觉系统。

**本次采用：**

- 费用统一显示人民币。
- 任务头像由产品主图自动截取。
- 新建任务先选择“完整广告创作”或“只剪现有素材”。
- 上传产品主视图后可选择生成三视图、九宫格或两者。
- 生成来源放在第三步确认界面的图片外部，不写入图片。
- 创意优先，产品事实与合规要求调整为硬边界。

**有意保留的模拟边界：** 当前产品头像、三视图和视频画面仍为原型示意，并未接入真实上传、图像生成、Seedance 或渲染服务。

**回归验证：** 已验证桌面端完整创作入口、纯剪辑路径、生成前确认门槛、第三步来源标签和审核台跳转；已在 390 × 844 手机视口验证主任务入口无横向溢出。测试页面未出现浏览器控制台错误。
